# Asset licensing

The MIT license in `LICENSE-CODE` applies only to repository code, scripts and original documentation.

It does **not** automatically apply to:

- UFC fighter photographs or portraits
- UFC branding
- football competition logos
- club logos
- trademarks belonging to sports organizations

Each asset should only be added if its source and usage rights are understood.

For assets that require attribution, record the source and license in `data/sources.json`.
